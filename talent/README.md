# talent/

Recruiter mode (`/talent`) output: `roles/<slug>/` holds each role's requirement spec, ranked shortlist and outreach drafts, and `talent_tracker.csv` logs every candidate considered.
Everything here except this README is gitignored and lives only in your private repo.
These files describe real people found in public sources. Under Thailand's PDPA, keep them purpose-limited to the role they were sourced for, and delete a person's data on request with `/talent --forget <login>`.
